THE UTSAV STUDIO – full project
================================
Files
  utsav-html.html        the website (icons are built in)
  server.js              backend (contact form, chat, serves the site)
  package.json / package-lock.json
  vercel.json            Vercel config (routes /images and /portfolio)
  render.yaml            Render config
  public/portfolio/      6 portfolio photos
  .gitignore

Deploy on Vercel (GitHub linked)
  1. Replace the files in your GitHub repo with these (keep your existing public/images folder if you want).
  2. Commit -> Vercel deploys automatically.

Run locally
  npm install
  npm start        -> http://localhost:8080
